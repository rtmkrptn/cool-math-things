# cool-math-things

Maths visualisations in Python using matplotlib.

## Files

| File | Description |
|------|-------------|
| monte_carlo_gaussian_random_walk.py | Simulates N Gaussian random walk paths with a live expected value line |
| numerical-system-of-des.py | Numerically solves a 2D system of DEs using Euler's method, animating trajectories from a grid of initial conditions |

## Requirements

pip install matplotlib numpy
